# Sociedad Anónima — crónica de una dinastía

Versión 32, preparada para GitHub Pages y uso como PWA en iPhone.

## Publicación en GitHub Pages

1. Crea un repositorio público llamado `sociedad-anonima`.
2. Sube **todos los archivos de esta carpeta a la raíz** del repositorio.
3. En GitHub: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
4. Espera a que GitHub Pages publique el sitio.
5. Abre la dirección HTTPS de GitHub Pages en Safari.
6. En iPhone: **Compartir → Añadir a pantalla de inicio**.

No renombres `index.html`, `manifest.webmanifest`, `sw.js` ni `icon-180.png`.
